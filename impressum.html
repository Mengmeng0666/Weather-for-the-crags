Haftungshinweis — Klettern auf eigene Gefahr

Alle Angaben auf dieser Seite (Routen, Schwierigkeitsgrade, Wandausrichtungen, Wetter- und Sonnendaten, Sperrzeiten) sind ohne Gewähr. Die Daten stammen aus öffentlich zugänglichen Quellen und können veraltet oder fehlerhaft sein. Klettern ist eine Risikosportart und erfolgt auf eigene Gefahr. Bitte prüft Bedingungen, Zustieg und insbesondere aktuelle Felssperrungen (Vogelschutz!) immer vor Ort bzw. bei den zuständigen Stellen (DAV, IG Klettern, Naturschutzbehörden).

Datenschutz

Diese Seite setzt keine Cookies und erstellt keine Nutzerprofile. Einstellungen (z. B. Sprache) werden ausschließlich lokal im Browser gespeichert (localStorage) und nicht übertragen.

Beim Aufruf der Seite werden technisch bedingt Daten (u. a. IP-Adresse) an folgende Dienste übermittelt:

· Hosting: GitHub Pages (GitHub Inc.) — Server-Logs
· CDN / Proxy und cookielose Reichweitenmessung: Cloudflare Web Analytics (Cloudflare Inc.)
· Wetterdaten: Open-Meteo API (Abruf direkt vom Browser)
· Kartenkacheln: OpenStreetMap (openstreetmap.org)
· JavaScript-Bibliotheken: unpkg.com, jsdelivr.net (CDN-Abrufe direkt vom Browser; Schriftarten werden lokal gehostet)

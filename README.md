# Alpenwand — 阿尔卑斯岩场天气/日照面板

一个纯静态网页(PWA),不需要后端、不需要 API key 就能跑起来。

## 现在能做什么

- **天气**:用 Open-Meteo(免费、无需注册)拉取未来4天的气温、云量、降水概率
- **日照**:用 SunCalc.js 按壁面朝向(你在编辑里填的角度)算出当天/未来几天大概几小时能晒到太阳,配一个小罗盘图直观显示
- **线路**:每个岩场下手动维护线路清单,区分「运动攀」和「多段」,记难度、朝向
- **今日指数**:综合降水概率和云量给出一个简单的 0-100 分,仅供参考
- 所有数据存在浏览器 `localStorage` 里,换设备/清缓存会丢失,注意导出备份(可以在浏览器开发者工具里手动导出 `localStorage.alpenwand_crags_v1`)

## 关于 theCrag 自动抓取

试过接了 theCrag 的 API,但有两个硬限制:

1. **需要开发者 Key**:去 https://www.thecrag.com/en/article/api 申请,不是我能帮你自动搞定的
2. **CORS 大概率会挡住浏览器直连**:theCrag 的 API 不是明确为纯前端调用设计的,浏览器发请求很可能被拦。App 里"theCrag 导入"那个按钮可以让你试,但如果失败了(大概率),说明确实需要一个小后端代理服务器来转发请求——这个我们可以之后单独再搭一个 Cloudflare Worker 之类的轻量代理,不复杂,但需要另起一个部署。

现阶段线路数据建议先手动维护,反正岩场就那几个,更新频率也不高。

## 部署(选一个,都免费)

### 方式A:Vercel(推荐,最快)
1. 去 vercel.com 注册,把这个文件夹拖进去部署(或者传到 GitHub 后 import 这个仓库)
2. 部署完给你一个 `xxx.vercel.app` 的链接

### 方式B:GitHub Pages
1. 新建一个 GitHub 仓库,把 `index.html`、`manifest.json`、`sw.js` 传上去
2. 仓库 Settings → Pages → 选 main 分支 → 保存
3. 几分钟后 `https://你的用户名.github.io/仓库名/` 就能访问

## 加到手机主屏幕

- iPhone Safari:打开链接 → 分享按钮 → "添加到主屏幕"
- Android Chrome:打开链接 → 右上角菜单 → "添加到主屏幕" / "安装应用"

添加后图标和体验跟原生 App 差不多,点开直接进面板。
